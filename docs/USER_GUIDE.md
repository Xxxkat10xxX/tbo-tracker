# Руководство инженера по ТО

Краткая инструкция для работы с tbo-tracker. Установка на сервер описана в [DEPLOY.md](DEPLOY.md) и [RASPBERRY_PI.md](RASPBERRY_PI.md).

## 1. Запуск

| Где | Как |
|---|---|
| Windows | запустить `run.bat` |
| Linux / macOS | `./run.sh` |
| Сервер | `docker compose up -d` |
| Raspberry Pi | служба запускается сама при включении |

После запуска откройте <http://localhost:8000> (на сервере – его адрес).

**Первый запуск.** Учётных записей ещё нет:
1. Введите одноразовый код настройки. Он выводится в консоли и записан в `data/setup-code.txt`; на Pi – `sudo tbo-ctl setup-code`.
2. Создайте администратора.
3. Администратор заводит инженеров в разделе «Пользователи».

## 2. Работа в течение смены

1. **Перед сменой** откройте «Обзор». Борт с красной меткой «Не допущен» не выпускайте: причина указана в карточке борта.
2. **После смены** загрузите журналы наземной станции в разделе «Импорт журналов» (JSON, CSV, Excel, PDF).
   - Отчёт покажет, сколько часов и циклов начислено каждому борту и узлу и какие сроки ТО наступили.
   - Строки с ошибками отклоняются с указанием причины. Остальные строки загружаются.
   - Повторная загрузка того же журнала ничего не начисляет.
3. **При замене или перестановке узла** откройте «Перестановка узлов» и перетащите узел на нужный борт или на склад. Подтвердите операцию. Наработка и история останутся за узлом.
4. **По уведомлению** выполните работу и отметьте её в «ТО и уведомления» → «Выполнить». Интервал этой работы начнётся заново, общая наработка узла не меняется.

Формат журналов – [LOG_FORMAT.md](LOG_FORMAT.md).

## 3. Безопасное завершение работы

| Где | Как |
|---|---|
| `run.bat` / `run.sh` | закрыть окно консоли или нажать Ctrl+C |
| Docker | `docker compose down` |
| Raspberry Pi | `sudo tbo-ctl stop`, затем выключение |

Каждая операция сохраняется сразу, одной транзакцией: при обрыве питания незавершённая операция не записывается частично. Перед обновлением сделайте копию: «Сервер» → «Резервные копии» или `sudo tbo-ctl backup`.

## 4. Типичные ошибки

| Сообщение | Причина | Что делать |
|---|---|---|
| «Повтор – не начислено» | этот файл или эти полёты уже загружены | ничего: защита от двойного учёта |
| «борт «…» не зарегистрирован в парке» | в журнале серийный номер, которого нет в «Парке БПЛА» | завести борт или исправить номер в журнале |
| «время посадки раньше или равно времени взлёта» / «полёт датирован будущим временем» | ошибка в строке журнала | исправить строку и загрузить файл ещё раз; применятся только исправленные строки |
| «Позиция занята» | на месте узла стоит другой | перетащить узел на занятое место: сервис предложит замену или обмен |
| «Узел в статусе «На обслуживании» – установка невозможна» | работа по узлу не закрыта | закрыть работу в «ТО и уведомления» |
| «Борт не допущен к полёту» | просрочена работа или после падения не выполнен осмотр | выполнить работу и отметить её |
| Не входит в систему, «учётная запись заблокирована» | много неверных паролей | подождать 15 минут (при повторах срок удваивается) или попросить администратора разблокировать |
