# Чек-лист запуска прототипа

Заполняется командой перед началом испытаний и подписывается вместе с экспертом. В нём фиксируется:
- можно ли запустить систему;
- можно ли начать все предусмотренные испытания;
- нужны ли доработки конструкции, ПО, конфигурации или замена основных компонентов.

Порядок испытаний – [TEST_METHODOLOGY.md](TEST_METHODOLOGY.md).

Отметка: ✓ – выполнено, ✗ – не выполнено, «–» – не применимо.

## 1. Сервер

| № | Проверка | Как проверить | Норма | Отметка |
|---|---|---|---|---|
| 1.1 | Служба запущена | `sudo tbo-ctl status` (Raspberry Pi) или `docker compose ps` | служба `active`, предупреждений нет | |
| 1.2 | Сервер отвечает | `curl http://АДРЕС/health` | `{"status": "ok"}` | |
| 1.3 | Вход в интерфейс | браузер → адрес сервера → вход инженером | открывается «Обзор» | |
| 1.4 | Время сервера верное | страница «Сервер» | расхождение с часами < 1 мин | |
| 1.5 | Данные для испытаний | «Парк БПЛА»: борта и узлы заведены; для демонстрации – демо-режим | борт испытаний «В эксплуатации», допущен | |
| 1.6 | Резервная копия перед испытаниями | `sudo tbo-ctl backup` или «Сервер» → «Резервные копии» | копия создана | |

## 3. Борт: сборка и безопасность

| № | Проверка | Как проверить | Норма | Отметка |
|---|---|---|---|---|
| 3.1 | Тип и размер борта | паспорт борта, замер | мультироторный, диагональ рамы ≤ 10″ (требование чемпионата) | |
| 3.2 | Крепления узлов | осмотр, покачивание | полётный контроллер, Orange Pi, GPS, камера, дальномер закреплены, люфта нет | |
| 3.3 | Кабели и разъёмы | осмотр | закреплены, не касаются винтов, без натяжения на разъёмах; открытых токоведущих частей нет | |
| 3.4 | Винты и моторы | осмотр | винты целые, затянуты, направление по схеме производителя | |
| 3.5 | Аккумулятор | вольтметр или QGroundControl | заряжен (≥ 3,75 В на элемент), закреплён ремнём, без вздутия | |
| 3.6 | Пульт и Kill Switch | включить пульт, переключить канал Kill Switch на земле без винтов | моторы останавливаются немедленно | |
| 3.7 | Failsafe PX4 | QGroundControl → Safety | потеря пульта – Land или RTL; низкий заряд; геозона; `COM_DISARM_LAND` > 0 | |

## 4. Борт: программная часть

| № | Проверка | Как проверить | Норма | Отметка |
|---|---|---|---|---|
| 4.1 | Связь Orange Pi с PX4 | `rostopic echo -n1 /mavros/state` | `connected: True` | |
| 4.2 | Служба агента | `systemctl status tbo-agent` | `active (running)` | |
| 4.3 | Борт на связи | «Борты на связи» | «На связи», видны батарея, GPS, режим, исполнитель | |
| 4.4 | Поток акселерометра | панель полёта, проверки борта | предупреждения «нет потока IMU» нет | |
| 4.5 | Пробная подготовка | миссия → «Отправить план на борт» | все проверки ✓, «Готов к старту» | |
