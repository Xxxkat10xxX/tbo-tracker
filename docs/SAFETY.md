# Безопасность и обслуживаемость

Здесь собраны меры безопасной эксплуатации и способы доступа к заменяемым узлам, настройкам и программным модулям.
Монтаж борта выполнен по документации производителя Skyris Technic 6S ([docs.skyris.ru/technic6S](https://docs.skyris.ru/technic6S/)).
tbo-tracker не меняет проводку и полётный контроллер: на борт ставится только программная служба на Orange Pi.
Фактическое состояние борта фиксируется перед испытаниями по [чек-листу запуска](LAUNCH_CHECKLIST.md), раздел 3.

## 1. Сборка и соединения

| Что проверяется | Требование | Где фиксируется |
|---|---|---|
| Крепление узлов | полётный контроллер, Orange Pi, GPS-модуль, камера и дальномер стоят на штатных креплениях рамы, люфта нет | чек-лист запуска, 3.2 |
| Кабели | закреплены вдоль лучей и рамы, не касаются винтов, разъёмы без натяжения | чек-лист запуска, 3.3 |
| Токоведущие части | силовые разъёмы и пайка изолированы, открытых проводников нет | чек-лист запуска, 3.3 |
| Аккумулятор | закреплён ремнём, без вздутия, заряжен; агент перед полётом проверяет заряд: процент (`min_battery_pct`) или, если контроллер его не сообщает, напряжение на элемент (`min_cell_v`, 3,75 В) | чек-лист запуска, 3.5; проверка «Заряд батареи» |
| Винты и моторы | винты целые, затянуты, направление вращения по схеме производителя | чек-лист запуска, 3.4 |
| Размер борта | мультироторный, диагональ рамы не более 10″ – требование чемпионата | чек-лист запуска, 3.1 |

## 2. Безопасность полёта

| Мера | Где задана |
|---|---|
| **Kill Switch** на отдельном канале пульта – мгновенная остановка моторов | пульт и PX4; проверка на земле без винтов, чек-лист 3.6 |
| **Пилот главнее автопилота**: переключение режима на пульте забирает управление, программа на борту прекращает команды | PX4, агент ([DRONE.md](DRONE.md), раздел 4) |
| **Failsafe PX4**: потеря пульта – Land или RTL, низкий заряд, геозона; потеря OFFBOARD – `COM_OBL_RC_ACT` | QGroundControl → Safety, чек-лист 3.7 |
| **Пределы полёта в двух местах**, действует более строгий:<br>- сервер: высота 120 м, удаление 2000 м, заряд ≥ 50 %; в помещении 3 м, 20 м, 2 м/с;<br>- борт: `[limits]` в `agent.conf` | `.env` сервера (`TBO_DRONE_*`), `/etc/tbo-agent/agent.conf` |
| **Допуск по ТО**: борт с просроченной работой, исчерпанным ресурсом или неосмотренный после удара не допускается к полёту | сервер, раздел «ТО и уведомления» |
| **Защита от ошибочного старта**: «Старт» только из «Готов к старту», с подтверждением оператора; команда действует 15 с; перед стартом план сверяется в PX4 повторно | сервер и агент |
| **Проверка плана**: хеш плана, принадлежность борту, обратное чтение миссии из PX4 | агент |
| **Первые полёты** – на малой высоте, в открытом месте, с пилотом на пульте в режиме Position | регламент команды |

## 3. Безопасность данных и связи

- Вход только по учётным записям. Пароли хранятся как хеш Argon2id. Роли: администратор, инженер, наблюдатель. Все изменения пишутся в журнал аудита ([SECURITY.md](SECURITY.md)).
- Борт подключается по **токену устройства**:
  - 256 бит, на сервере хранится только хеш;
  - на борту – файл с правами 600;
  - агент видит только свой борт.
- HTTPS через Caddy. Агент не следует перенаправлениям и не использует прокси из окружения.
- Службы ограничены в systemd. Агент: `NoNewPrivileges`, `ProtectSystem=full`, запись только в `/var/lib/tbo-agent`.

## 4. Обслуживаемость

### 4.1 Заменяемые узлы борта

Узлы борта – стандартные модули с разъёмными соединениями, они меняются без разрушения конструкции. Порядок замены – по документации производителя.

После замены узел переставляется в tbo-tracker перетаскиванием:
- новый узел получает свой электронный паспорт;
- снятый узел уходит в резерв или ремонт со всей историей наработки.

| Узел | Доступ | Что сделать в tbo-tracker после замены |
|---|---|---|
| Винты, моторы, регуляторы (ESC) | лучи рамы, разъёмные соединения | «Перестановка узлов»: снять в ремонт, установить резервный |
| Аккумулятор | ремень крепления | – |
| Полётный контроллер | штатное крепление, разъёмы | перестановка узла; калибровки в QGroundControl |
| Orange Pi 5 Pro | штатное крепление, разъёмы | установить агент: `sudo ./install.sh` и токен из «Борты на связи» |
| GPS-модуль, камера, дальномер | штатные крепления | – |

### 4.2 Настройки без изменения кода

| Что настраивается | Где |
|---|---|
| Адрес сервера, сертификат, исполнитель полёта, пределы борта | `/etc/tbo-agent/agent.conf` |
| Токен устройства | «Борты на связи» → «Новый токен», затем `sudo ./install.sh --token` |
| База данных, адрес сайта, пределы полётов, каналы уведомлений | `.env` сервера, страница «Сервер» |
| Регламенты ТО, ресурс узлов, типы бортов и узлов | интерфейс: «Регламенты», «Ресурс», «Свои типы узлов» |
| Параметры PX4 (failsafe, навигация) | QGroundControl |

### 4.3 Программные модули

| Модуль | Обслуживание |
|---|---|
| Сервер | `sudo tbo-ctl status`, `logs`, `restart`; обновление `sudo tbo-ctl update` с копией данных перед обновлением; резервные копии `backup` / `restore` |
| Бортовой агент | `systemctl status tbo-agent`, `journalctl -u tbo-agent -f`; переустановка `sudo ./install.sh`; журналы полётов в `/var/lib/tbo-agent` |
| Код | модули независимы: `app/services/*` – по одному на функцию; `agent/tbo_agent/*` – исполнители, регистратор, проверки; интерфейс `app/static/js` – по файлу на раздел |
| Развёртывание заново | `deploy/field/deploy.sh` – сервер и агент одной командой; [DEPLOY.md](DEPLOY.md), [RASPBERRY_PI.md](RASPBERRY_PI.md) |
