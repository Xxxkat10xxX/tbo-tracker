# Ролик tbo-tracker (15 с, 1920×1080, 60 fps)

Готовое видео: [`tbo-tracker-launch.mp4`](tbo-tracker-launch.mp4).

## Как устроено

* `launch.html` (разметка) + `launch.css` (стили) + `launch-core.js` (время, камера) + `launch-scenes.js` (сцены). Кадр полностью вычисляется из времени в `window.seek(t)`:
  без CSS-анимаций, таймеров и состояния между кадрами. Пружины и экспоненциальные кривые — функции времени.
* Интерфейс — векторная пересборка реальных экранов tbo-tracker (те же правила `app/static/css/app.css`,
  тексты и цифры из демо-данных сценария перестановки: FC7-0102, 133,8 ч → +4,85 ч, ТО ПК 96,1 → 100,9 / 100 ч).
  Цвета статусов приглушены: акцентный синий принадлежит только сквозному объекту — синей капсуле —
  и ключевому слову «предотвращён».
* Сквозной объект — **синяя капсула** (кнопка основного действия и заливка шкалы ресурса):
  зачёркивание → «⇄ Переставить на другой борт» → «Переставить» → бейдж «сейчас» → «Импортировать» →
  «+4,85» → шкала ТО → счётчик в аналитике → круг логотипа с шевроном.
* Саундтрек пишется кодом: `window.renderSoundtrack()` (Web Audio, `OfflineAudioContext`, 120 BPM, фа минор),
  бочка на каждую долю, удар на каждой смене сцены, дроп на 10,0 с.
* Шрифт — Inter (так интерфейс отрисовывается; крупные титры — Inter Display, та же гарнитура).

## Пересборка

Нужны Node.js с Playwright (Chromium) и ffmpeg с libx264.

```bash
node render.js beats      # по кадру на каждую долю + контактный лист out/beats_sheet.png
```

```bash
node render.js audio      # out/soundtrack.wav
```

```bash
node render.js full       # 60 fps × 3 субкадра → ffmpeg tmix (смаз) → tbo-tracker-launch.mp4 со звуком
```

Субкадры берутся в моменты `k/60 + j/180`, поэтому склейки (кратные 1/60 с) никогда не смешиваются внутри кадра.
